## 1. Сонголтууд ба төлөөлөх утгууд

| Сонголт | Төлөөлөх утгууд (эквивалент анги) |
| --- | --- |
| studentID-гийн хүчинтэй байдал | идэвхтэй / идэвхгүй / байхгүй |
| Оюутны үзсэн хичээлүүд (coursesTaken) | урьдачийг хангана / хангахгүй |
| courseID-гийн хүчинтэй байдал | байгаа / байхгүй |
| Хичээлийн урьдач нөхцөл | бүгд үзсэн / огт үзээгүй / зарим нь үзсэн |

## 2. Спецификаци

| № | Тодорхойлолт | Хүлээгдэх статус | Хүлээгдэх result |
| --- | --- | --- | --- |
| 1 | Happy path: идэвхтэй оюутан, урьдач CS201-г үзсэн | 201 | OK |
| 2 | Байхгүй оюутан | 200 | ERROR_NO_STUDENT |
| 3 | Идэвхгүй оюутан | 200 | ERROR_INACTIVE_STUDENT |
| 4 | Идэвхтэй оюутан, байхгүй хичээл | 200 | ERROR_NO_COURSE |
| 5 | Урьдач нөхцөл огт хангаагүй | 200 | ERROR_PREREQUISITES |
| 6 | Урьдачийн зарим нь үзсэн (CS201 үзсэн, CS201+CS202 шаардлагатай) | 200 | ERROR_PREREQUISITES |
| 7 | Давхар алдаа: байхгүй оюутан + байхгүй хичээл | 200 | ERROR_NO_STUDENT |
| 8 | Давхар алдаа: идэвхгүй оюутан + байхгүй хичээл | 200 | ERROR_INACTIVE_STUDENT |
| 9 | Хязгаар: урьдачгүй хичээл, хоосон coursesTaken | 201 | OK |
| 10 | Хязгаар: courseID талбар дутуу | 400 | ERROR_BAD_REQUEST |
Тэмдэглэл: 7, 8-р тестийн хүлээгдэх утга нь серверийн шалгах дарааллаас (оюутан, дараа нь хичээл) гарсан.
